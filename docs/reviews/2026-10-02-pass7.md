## Fell in verification

- F1-09: Reproduces on both trees, but the state is reached only by a hand edit pgpm does not document: dropping the pgpm_monolith_bound CHECK while its pgpm.transmute_inflight claim stands. docs/reference.md (pgpm.transmute_inflight) states the invariant this edit breaks: 'A row here means the table still carries a pgpm_monolith_bound CHECK and is refusing writes outside [lo, hi)'. The only documented ways to remove the bound are transmute_abort ('drops it and puts the table back exactly as it was', guide.md; reference.md transmute_abort) or the maintain_all reaper. Neither the guide nor the runbook tells an operator to drop the constraint by hand. The resume code relies on that same invariant on purpose (install.sql, resume comment above line 6529: 'no row can have landed outside the recorded range, because the CHECK was rejecting exactly those the whole time'). The consequence is also the documented state after a failed conversion ('If a conversion dies partway, the bound outlives it and the table goes on refusing those writes', guide.md), and transmute_abort clears it. The 23514 VALIDATE failure message is documented in guide.md as well. No defect in pgpm on a documented path.
- F9-04: Reproduces on both trees, but the state is a hypothetical no tree file is in, and it cannot produce a false certification without being caught. The wrapper's '0 ran' FAIL fires only when EVERY assertion in the file has no description: a single described assertion makes ran >= 1, and from then on pg_prove's exit code decides (grid_timezone.sh: `if [ "$ran" -eq 0 ]`). The other 4 (archive_identity_substitution, coverage_reset_identity, retire_identity_unreferenced, write_block_identity) are fixed to existing described files (tests/102, 129, 103, 104). The guard fails loudly, refusing a state it should accept. It never accepts a state it should refuse, so the rubric names no consequence. This is not #713: #713 is discriminate counting a LIVENESS-only failure as a catch, while this claim is about the wrapper's ran-count regex.
