## F18-02

- finder: F18
- location: `pgpm_core/install.sql:9508`
- lens: operator error
- tier: 4
- scenario: _transmute_refuse_staging_squatter tells the operator to type `drop table <schema>.<table>_pgpm_new` whatever relkind holds the staging name; against a sequence or a view that command fails ('is not a table'), so the remedy the refusal names does not repair the state it describes, where the sibling child-name and monolith-name refusals (#509, _relkind_noun) name what they found.
- root cause (verifier): _transmute_refuse_staging_squatter's relation refusal hard-codes the remedy 'drop table <nsp>.<rel>_pgpm_new' without asking the holder's relkind (its monolith and orphan-child siblings use _relkind_noun or name no statement), so for a sequence, view or index holding the staging name the statement the operator is told to type fails 42809 'is not a table'. Not documented (docs/reference.md only promises 'the up-front message and remedy'); no open issue shares the mechanism (#1217 is the CREATE's 23505 arm naming the wrong holder). Rebuilt: the original gated a LIVENESS check on the message containing a parenthesised drop statement, so a fix that names no statement (the monolith refusal's 'Drop or rename it') would still fail it; the rebuild treats the named statement as the thing tested, not a premise.

Reproduction: `repro.verified.sql`, the verifier's rebuilt reproduction. It supersedes the finder's `repro.sql`, which the verifier had to change before it proved the defect.

```sql
-- F18-02 (verified rebuild): the staging-name refusal's remedy is `drop table <nsp>.<rel>_pgpm_new` whatever holds
-- the name. A sequence holding it is refused with that remedy, and the remedy fails: "is not a table".
-- Rebuilt so the named statement is not itself a premise: a fix that names the holder's kind
-- ('drop sequence ...') or names no statement at all (the monolith refusal's 'Drop or rename it') passes; a
-- refusal that names a statement which fails against the holder it found does not.
create extension if not exists pgtap;
select plan(4);

create table public.f18s (id bigint primary key, ts timestamptz not null);
create sequence public.f18s_pgpm_new;

select is((select relkind::text from pg_class where oid = 'public.f18s_pgpm_new'::regclass), 'S',
          'LIVENESS: a sequence holds the staging name f18s_pgpm_new');

create function pg_temp.f18_refusal() returns text language plpgsql as $f$
begin
  call pgpm.transmute('public.f18s', 'id', 1000::bigint);
  return null;
exception when others then
  return sqlerrm;
end $f$;
select pg_temp.f18_refusal() as msg \gset
select ok(:'msg' like 'pg_partition_magician: public.f18s_pgpm_new already exists%',
          'LIVENESS: transmute refused on the held staging name: ' || coalesce(:'msg', 'no refusal'));

-- the statement the refusal names, if it names one (null otherwise)
select (regexp_match(:'msg', '\((drop [^)]+)\)'))[1] as remedy \gset

-- the defect: a statement the refusal tells the operator to type must run against the holder it found
select lives_ok(coalesce(nullif(:'remedy', ''), 'drop sequence public.f18s_pgpm_new'),
                'the remedy the refusal names (or, naming none, the holder''s own drop) runs: ' || coalesce(nullif(:'remedy', ''), '(none named)'));
select is(to_regclass('public.f18s_pgpm_new'), null, 'and the staging name is free afterwards');
select * from finish();
```
