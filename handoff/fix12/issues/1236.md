### F12-03 (finder F12, `scripts/check_quoted_splices.py:365`, lens: fresh surface, claimed tier 5)

**Scenario:** the Quoted splices lint, which since #1179 claims to read every assignment by value wherever a statement starts, passes an install file whose unmarked quote_ident'd list (v_cols := quote_ident(..) || ..., spliced with %s) is preceded by a /* block comment */: strip_noise blanks only -- comments and ASSIGN anchors on the raw text after ;/begin/then, so the assignment is never read; the same function without the comment is refused, as both should be

<details><summary>Reproduction <code>repro.sh</code> (install: pgpm_core/install.sql)</summary>

```bash
#!/usr/bin/env bash
# scripts/check_quoted_splices.py (CI's `Quoted splices` job) passes an install file carrying the #409 shape,
# an unmarked quote_ident'd column list spliced with %s, when a /* block comment */ precedes the assignment:
# strip_noise blanks `--` comments only, so the assignment is not at a statement start and is never read.
# Runs the TREE's script on a scratch copy of the tree's install files with one function appended.
set -u

if [ "$rc" = 0 ]; then echo "ok - fixture: the lint passes the tree's install files as shipped"; else echo "not ok - fixture: the lint fails the tree as shipped"; cat "$W/out"; fail=1; fi

  v_n := 0;

  execute format('select count(*) from (select %s from %s) s', v_cols, p_rel) into v_n;

end;
\$\$;
SQL

# A: the shape with no comment: the lint must refuse it (proves the edit reaches the file the lint reads)

# B: the same function, its assignment preceded by a block comment
cp "$TREE/pgpm_core/install.sql" "$W/pgpm_core/install.sql"; body "/* quoted list */" >> "$W/pgpm_core/install.sql"
grep -q "v_cols := quote_ident('id')" "$W/pgpm_core/install.sql" && echo "ok - LIVENESS: (B) the edited install carries the same unmarked v_cols assignments"
rc=$(lint)
if [ "$rc" != 0 ] && grep -q 'v_cols is assigned from an identifier-quoting expression but is not _q-suffixed' "$W/out"; then
  echo "ok - the unmarked quoted list v_cols is refused behind a block comment too"
else
  echo "not ok - the lint exits $rc and passes the unmarked quoted list v_cols behind a /* block comment */"; cat "$W/out"; fail=1
fi
exit $fail
```

### F12-05 (finder F12, `scripts/check_quoted_splices.py:163`, lens: fresh surface, claimed tier 5)
