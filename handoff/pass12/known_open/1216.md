### F18-05 (finder F18, `pgpm_core/install.sql:9573`, lens: fresh surface, claimed tier 2)

**Scenario:** _transmute_refuse_child_holders treats any relation in pg_inherits as not a holder, so a partition of another parent named <rel>_p<label> passes the preflight and both cutover re-asks; obtain steps over it, and the conversion completes with the forward cell right past the monolith unbuilt ([1000,2000) missing beside [2000,3000) built) and nothing refused or logged, so every write with a key in that cell fails with no partition found until the name is freed, where a standalone relation at the same name is refused up front.

-- parent that holds a forward cell's name is not a holder; obtain then steps over it (to_regclass finds it,
-- pgpm.part does not), and the conversion completes with that cell unbuilt and nothing refused or logged.

select ok(exists (select 1 from pg_inherits where inhrelid = to_regclass(format('public.%I', :'held'))

\set ON_ERROR_STOP on
select ok(exists (select 1 from pg_inherits where inhrelid = to_regclass(format('public.%I', :'held'))
                    and inhparent = 'public.f18_other'::regclass),

select is((select count(*)::int from pgpm.log where parent_table = 'public.f18k'::regclass and action in ('transmute', 'fail_obtain_name')),
          0, 'no transmute was logged for it (and nothing about the hole)');
select * from finish();
